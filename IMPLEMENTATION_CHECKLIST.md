# Implementation checklist

## Phase 1: Build the pipeline
- [ ] Create virtual environment
- [ ] Install `requirements.txt`
- [ ] Run the ingestion step
- [ ] Inspect raw columns
- [ ] Run quality checks
- [ ] Confirm units using the source codebook
- [ ] Load curated CSV

## Phase 2: Research analysis
- [ ] Pick 3–5 countries
- [ ] Compare electricity demand growth
- [ ] Compare fossil vs renewable shares
- [ ] Inspect oil/gas/coal production and consumption
- [ ] Document at least 5 findings with source links
- [ ] Document at least 3 limitations

## Phase 3: Forecasting
- [ ] Backtest all candidate models
- [ ] Record MAE and RMSE
- [ ] Choose model by a transparent metric
- [ ] Produce 3-year forecast
- [ ] Explain why uncertainty remains high

## Phase 4: Dashboard
- [ ] Build Streamlit dashboard
- [ ] Export Power BI-ready CSVs
- [ ] Build 3 Power BI pages
- [ ] Add source attribution
- [ ] Add data-quality section

## Phase 5: GitHub
- [ ] Add screenshots
- [ ] Add architecture diagram
- [ ] Add README
- [ ] Add dataset source links
- [ ] Add reproducibility commands
- [ ] Add tests
- [ ] Add license
- [ ] Push repository

## Phase 6: Resume
- [ ] Add project only after implementation
- [ ] Add only measured metrics
- [ ] Link GitHub repository
- [ ] Practice the interview guide
